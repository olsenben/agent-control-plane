## Conclusion

The RTX 2070 host is powered off or asleep and has been since roughly 12 hours
before this wave. No live C1 observation against the real 2070 is obtainable
until a human brings it back online. Substituting the 3080 was rejected: it
would change the C1 evaluated identity (`MODEL_2070_*`), which the wave brief
forbids.

This also explains CT103 `/readyz` reporting `degraded`, the same condition Wave
A recorded on 2026-08-16.
